# IdeaNest

IdeaNest は、思いついたアイデアを素早く保存し、あとから検索・整理できる **ローカル利用前提のカード型メモツール** です。

> **このリポジトリは v0.1.0 のプロトタイプです。** 一気通貫の動作確認を最優先しており、UI の作り込みや細かな例外処理は最低限です。

## IdeaNest とは

- アイデア 1 件 = カード 1 枚
- 思いついた順に素早く追加できる
- タグで分類できる
- ピン留め / アーカイブができる
- すべてローカルの単一 JSON ファイル (`.ideanest`) に保存する

「整理する前に、まず溜める」ためのツールです。

## NoteNest との違い

| 観点 | NoteNest | IdeaNest |
| --- | --- | --- |
| 主目的 | プロジェクト管理・ノート管理 | アイデアの即時メモと検索 |
| 主単位 | プロジェクト / ノート | カード |
| 画面構成 | プロジェクト×ツリー×エディタ | カードのフラット一覧 |
| 重視点 | 構造化と進捗管理 | スピードと一覧性 |
| 想定利用 | じっくり書く | パッと書いて後で探す |

IdeaNest は NoteNest の縮小版ではなく、**「とにかく雑に放り込めるアイデアの巣 (nest)」** という別の役割を担います。

## 画面方針 (v0.5.2)

IdeaNest は「カード一覧を主役にする軽いアイデアボード」というコンセプトに沿って、
v0.1.2 で画面の見た目を以下のように整理しました。

- 画面全体の背景を薄いグレー (`#F6F7F9`) にし、白いカードを浮き上がらせる。
- カードは角丸 + 余白 + 薄い影で表現し、枠線を排除する。
- カード色は淡いパステルとし、文字の可読性を優先する。
- タグは小さなチップ風に表示する (タイポグラフィの階層を整える)。
- 右下の「＋」ボタンは暖色アクセント (`#E8773A`) で、主要導線として強調する。
- 標準 WPF のボタン立体感を抑え、フラットで余白の大きい見た目に統一する。

外部 UI ライブラリ (MahApps.Metro / Material Design / Fluent UI 等) や
WebView2 は導入せず、WPF 標準機能の範囲で実現しています。

## 主な機能 (v0.5.2)

- アイデアカードの追加・編集・削除
- カード型の一覧表示 (ピン留めが上に来る) — カード操作ボタンはホバー時のみ表示
- **並び順切替** (色フィルタ行の「並び:」コンボボックス) — 更新日時順 (既定) / 作成日時順 / タイトル順 / シャッフル
- **シャッフル表示** — `🔀` 再シャッフルボタンで通常カードの順番をランダムに混ぜ直し可能 (ピン留めは上部固定)
- **カードサイズ切替** (色フィルタ行右端の「S / M / L」ボタン、または `表示 → カードサイズ`) — S: 184×148 / M: 252×212 (デフォルト) / L: 340×280
- 左サイドのタグパネルは折りたたみ可能 (検索バー左の「タグ ◀ / タグ ▶」ボタン、または `表示 → タグパネル`)
- **画面右下の「＋」ボタン** または `Ctrl+Shift+N` から新規カード作成ダイアログを開く
- 新規作成・編集ともに同じダイアログでタイトル・本文・タグ・色・ピン・アーカイブを入力
- タイトル未入力時は本文の先頭からタイトルを自動生成
- キーワード検索 (タイトル / 本文 / タグ)
- タグによる絞り込み
- カード色による絞り込み (検索・タグ・アーカイブ表示と AND で組み合わせ可能)
- アーカイブ表示の切替
- 表示件数バッジ (表示件数と全件数が一致するとき `12件`、絞り込み中またはアーカイブが隠れているとき `5件 / 全12件`)
- カード 0 件・絞り込み 0 件の状況に応じた空状態ガイダンス
- 検索欄のクリアボタン (`✕`) と `Ctrl+F` / `Esc` のキーボード操作
- 削除時にアーカイブ案内を含む確認ダイアログ
- タグ管理ダイアログ (編集 → タグ管理…) でタグのリネーム・マージ・削除
- 左ペインのタグ一覧にカード件数を表示
- タグ入力の正規化 (前後空白除去・先頭 `#` 除去・重複排除)
- **Markdown風エクスポート** (`ファイル → エクスポート → Markdown風テキスト...`) で現在表示中のカードを `.md` として書き出し
- **NoteNest向けエクスポート** (`ファイル → エクスポート → NoteNest向けテキスト...`) で NoteNest に貼り付けやすい形式でファイル出力。実行前にオプションダイアログで `[NOTE]`/`[TODO]` マーカーやメタ情報の出力有無を選択可能
- **クリップボードコピー**: カードを右クリック → `Markdown形式でコピー` で1枚、`編集 → 表示中カードをMarkdown形式でコピー` (`Ctrl+Shift+C`) で全件コピー。`編集 → 表示中カードをNoteNest向けにコピー` で NoteNest 向け形式で全件コピー (オプション指定あり)
- `.ideanest` ファイルへの保存・読込
- 名前を付けて保存
- **自動保存** (既存 `.ideanest` ファイルを開いている場合、編集後 2 秒で自動保存)
- 画面下部の保存状態表示 (`保存済み` / `未保存の変更あり` / `自動保存中...` / `自動保存しました HH:mm` / `自動保存に失敗しました`)
- 未保存変更時の確認ダイアログ / タイトルバーの `*` 表示
- 保存時に `.bak` を自動生成 (自動保存時も同様)
- ウィンドウサイズ・検索文字列・選択中タグ・選択中色・アーカイブ表示状態をファイルに記録

### 新規カードの作り方

1. 画面右下のオレンジ系の丸い「＋」ボタンをクリック (またはキーボードで `Ctrl+Shift+N`)
2. ダイアログでタイトル・本文・タグ・色・ピン留め・アーカイブを入力
3. `OK` で確定すると一覧に追加される

タイトルを空にした場合は本文の先頭行からタイトルが自動生成されます。
タイトル・本文の両方が空のままで `OK` した場合、カードは作成されません (`キャンセル` と同じ扱い)。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+N`        | 新規ワークスペース (現在の `.ideanest` を閉じる) |
| `Ctrl+O`        | `.ideanest` を開く |
| `Ctrl+S`        | 保存 |
| `Ctrl+Shift+S`  | 名前を付けて保存 |
| `Ctrl+Shift+N`  | 新規カード作成ダイアログを開く |
| `Ctrl+Shift+C`  | 表示中カードをまとめて Markdown 形式でクリップボードにコピー |
| `Ctrl+F`        | 検索欄にフォーカス (既存の検索文字列を全選択) |
| `Esc` (検索欄)  | 検索文字列をクリア / もう一度押すとフォーカスを外す |

## 起動方法

### 必要環境

- Windows 10 / 11
- .NET 8 SDK (`dotnet --version` が `8.0.x` を返すこと)

### ビルドと起動

```powershell
git clone <this-repo>
cd ideanest
dotnet build
dotnet run --project src/IdeaNest/IdeaNest.csproj
```

> **注:** WPF は Windows 専用です。Linux / macOS では `dotnet build` できません。
> ただし、Models/Services を切り出した `tools/IdeaNest.Smoke` プロジェクトは
> クロスプラットフォームで動作し、JSON 保存・読込のラウンドトリップを検証できます。
>
> ```bash
> dotnet run --project tools/IdeaNest.Smoke
> ```

## `.ideanest` ファイルについて

- UTF-8 の JSON ファイル
- アプリ起動中に「保存」「名前を付けて保存」で生成される
- 拡張子は `.ideanest`
- 保存時、同フォルダに `*.ideanest.bak` を生成 (直前の保存内容)
- 形式は以下のとおり

```json
{
  "version": "0.1.0",
  "workspaceName": "IdeaNest",
  "ideas": [
    {
      "id": "uuid",
      "title": "アイデアのタイトル",
      "body": "アイデア本文",
      "tags": ["UI", "開発"],
      "color": "yellow",
      "isPinned": false,
      "isArchived": false,
      "createdAt": "2026-06-02T10:00:00",
      "updatedAt": "2026-06-02T10:00:00"
    }
  ],
  "settings": {
    "searchText": "",
    "selectedTag": "",
    "selectedColor": "",
    "showArchived": false,
    "tagPanelOpen": true,
    "cardSize": "medium",
    "sortMode": "UpdatedDesc",
    "windowWidth": 1100,
    "windowHeight": 700
  }
}
```

### Markdown風エクスポートについて

`ファイル → エクスポート → Markdown風テキスト...` から、現在の表示条件に一致しているカードを `.md` ファイルとして書き出せます。

- 検索文字列・タグフィルタ・色フィルタ・アーカイブ表示の条件がすべてエクスポート対象に反映されます。
- カードの並び順 (ピン留め優先 → 更新日時降順) も出力順に反映されます。
- 表示中のカードが 0 件の場合はエクスポートされず、メッセージが表示されます。
- 出力ファイルは BOM なし UTF-8 で保存されます。
- `.ideanest` への保存とは独立しており、保存形式には影響しません。

### NoteNest向けエクスポートについて

`ファイル → エクスポート → NoteNest向けテキスト...` から、NoteNest のノート本文に貼り付けやすい形式で `.md` ファイルを書き出せます。

- 実行前にオプションダイアログが表示され、以下を選択できます:
  - `[NOTE] IdeaNestから移行したアイデア` を付ける (初期値: ON)
  - `[TODO] 採用判断` を付ける (初期値: OFF)
  - タグ・色・作成日・更新日などのメタ情報を含める (初期値: ON)
- カードごとに番号付きの `## N. タイトル` 形式で出力されます。
- 検索・タグ・色・アーカイブ表示の条件がすべてエクスポート対象に反映されます。
- `.notenest` ファイルの直接生成・既存ファイルへの追記は行いません。貼り付けて使う運用を想定しています。

## 自動保存について (v0.4.0)

- 既存の `.ideanest` ファイルを開いている場合、編集が止まってから約 2 秒後に自動保存されます。
- 新規未保存状態 (タイトルバーに `(未保存)` と表示) では自動保存されません。保存先を勝手に決めないため、初回は `Ctrl+S` (または `名前を付けて保存`) で保存先を指定してください。
- 自動保存が成功するとタイトルバーの `*` が消え、画面下部に `自動保存しました HH:mm` と表示されます。
- 自動保存が失敗すると `*` が残り、画面下部に `自動保存に失敗しました` と表示されます。次回の手動保存または編集による再試行を促します。
- 手動保存 (`Ctrl+S` / `Ctrl+Shift+S`) は引き続き利用できます。
- 自動保存時にも `.bak` (1 つ前の保存内容) が更新されます。世代バックアップは行いません。

## v0.5.2 時点の制限

- **プロトタイプ段階です。** UI の細部・例外の見せ方は最低限です。
- 画面設定 (ウィンドウサイズや検索条件など) はファイルに保存されますが、起動時の復元は読み込んだ `.ideanest` 経由のみです。
- 並び順は更新日時順 / 作成日時順 / タイトル順 / シャッフルから選べますが、手動並べ替え (ドラッグ) はできません。
- ピン留めカードはどの並び順でも上部に固定され、ピン留め内は更新日時降順固定です。
- シャッフルの具体的な順序は保存されません (`sortMode` のみ保存)。再起動時は新規シャッフルになります。
- カードの色は内蔵の固定パレット (8 色) のみです。

## 対象外機能 (v0.1.0)

将来検討としており、本バージョンには含めていません。

- 画像貼り付け
- 添付ファイル
- リマインダー
- チェックリスト
- タスク管理
- カレンダー連携
- クラウド同期
- 共同編集
- Markdown プレビュー
- NoteNest との直接連携
- AI 要約
- 自動分類
