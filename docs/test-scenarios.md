# 手動テストシナリオ (v0.7.0)

Windows 上で `dotnet run --project src/IdeaNest/IdeaNest.csproj` を実行し、各シナリオを上から順に試す。
すべてが成功すれば v0.7.0 の受入条件を満たしているとみなす。

| # | シナリオ | 操作 | 期待結果 |
| --- | --- | --- | --- |
| 1 | 起動できる | アプリを起動し、スタートダイアログで「新規プロジェクトを開始する」を選ぶ | メインウィンドウが表示される / タイトルバーが `IdeaNest - (未保存)` / 画面上部に新規入力欄が **ない** |
| 2 | 右下の「＋」ボタンが表示される | 起動直後の画面を確認 | カード一覧エリアの右下に丸い暖色 (オレンジ系) の `＋` ボタンが表示される / ホバーで `新しいアイデアを追加 (Ctrl+Shift+N)` のツールチップ |
| 3 | 「＋」ボタン押下で新規カード作成ダイアログが開く | 右下の `＋` をクリック | タイトルバーが「新規アイデア」のダイアログが開く / タイトル / 本文 / タグ / 色 / ピン / アーカイブの入力欄がある |
| 4 | ダイアログから新規カードを作成できる | 「タイトル」「本文」「タグ (例: `UI, 開発`)」を入れて `OK` | 一覧にカードが追加され、タイトルバーに `*` が付く |
| 5 | タイトル未入力でも本文からタイトルが自動生成される | タイトル空欄のまま本文だけ入れて `OK` | カードが追加され、本文の先頭行 (最大 40 文字) がタイトル位置に表示される |
| 6 | タイトル・本文が空の場合は空カードが作成されない | 何も入力せず `OK` | カードは追加されない / `*` も付かない (キャンセル相当) |
| 7 | `Ctrl+Shift+N` でもダイアログを開ける | 任意のフォーカスで `Ctrl+Shift+N` | 同じ「新規アイデア」ダイアログが開く |
| 8 | 既存カードの編集に影響がない | カードをダブルクリック (または `編集`) → 内容を変更 → `OK` | タイトルバーが「アイデア編集」と表示される / カードが更新され `*` が付く |
| 9 | カードを削除できる | カードの `削除` を押す → 確認で `OK` | カードが一覧から消える / `*` が付く |
| 10 | タグを設定できる | 編集ダイアログでタグを `UI, 設計` に変更して `OK` | カード下部のタグ表示が `#UI #設計` になる / 左ペインのタグ一覧にも反映される |
| 11 | タグで絞り込みできる | 左ペインで `#UI` をクリック | UI タグを持つカードだけが表示される / `(すべて)` ボタンで解除できる |
| 12 | キーワード検索できる | 上部検索欄に語句を入れる | タイトル / 本文 / タグのいずれかに一致するカードのみ表示される |
| 13 | ピン留めできる | カードの 📌 ボタンを押す | ★ が表示され、カードが一覧の先頭側に移動する |
| 14 | アーカイブできる | カードの 📥 ボタンを押す | 通常表示ではそのカードが消える |
| 15 | アーカイブ表示を切り替えできる | 上部の `アーカイブを表示` をチェック | アーカイブ済みカードも一覧に並ぶ / 解除すると再び消える |
| 16 | 保存できる | `ファイル > 名前を付けて保存` → 任意のフォルダに `test.ideanest` で保存 | ファイルが作成される / タイトルバーが `IdeaNest - test.ideanest` (`*` なし) になる |
| 17 | 読込できる (新規作成カードも保持される) | `ファイル > 新規作成` で空にしたあと `ファイル > 開く` から `test.ideanest` を選ぶ | カード一覧 / タグ一覧 / 検索文字列 / アーカイブ表示状態が復元され、`＋` ボタンで作ったカードも残っている |
| 18 | 未保存変更がある状態で終了時に確認が出る | カードを追加し未保存のまま `×` で閉じる | 「未保存の変更があります。保存しますか？」の確認が出る / `キャンセル` で閉じない |

## 補助: 自動スモークテスト

UI を伴わない部分 (Models / Services / JSON ラウンドトリップ) は、
クロスプラットフォームで動く `tools/IdeaNest.Smoke` でも確認できる。

```bash
dotnet run --project tools/IdeaNest.Smoke
```

`ALL CHECKS PASSED` と表示されれば、保存形式と読み書きは健全。
