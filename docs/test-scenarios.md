# 手動テストシナリオ (v0.1.0)

Windows 上で `dotnet run --project src/IdeaNest/IdeaNest.csproj` を実行し、各シナリオを上から順に試す。
すべてが成功すれば v0.1.0 の受入条件を満たしているとみなす。

| # | シナリオ | 操作 | 期待結果 |
| --- | --- | --- | --- |
| 1 | 起動できる | アプリを起動する | メインウィンドウが表示される / タイトルバーが `IdeaNest - (未保存)` |
| 2 | 新規カードを追加できる | 上部入力欄に「タイトル」「本文」「タグ (例: `UI, 開発`)」を入力 → `追加` | カードが一覧に現れ、タイトルバーに `*` が付く |
| 3 | 本文だけでカードを追加できる | タイトル空欄のまま本文だけ入力 → `追加` | カードが追加される (エラーにならない) |
| 4 | タイトル未入力時にタイトルが自動生成される | シナリオ 3 のカードを確認 | 本文の先頭行 (最大 40 文字) がタイトル位置に表示される |
| 5 | カードを編集できる | カードをダブルクリック (または `編集`) → 内容を変更 → `OK` | カードの表示が更新され、更新日時が変わる / `*` が付く |
| 6 | カードを削除できる | カードの `削除` を押す → 確認で `OK` | カードが一覧から消える / `*` が付く |
| 7 | タグを設定できる | 編集ダイアログでタグを `UI, 設計` に変更して `OK` | カード下部のタグ表示が `#UI #設計` になる / 左ペインのタグ一覧にも反映される |
| 8 | タグで絞り込みできる | 左ペインで `#UI` をクリック | UI タグを持つカードだけが表示される / `(すべて)` ボタンで解除できる |
| 9 | キーワード検索できる | 上部検索欄に語句を入れる | タイトル / 本文 / タグのいずれかに一致するカードのみ表示される |
| 10 | ピン留めできる | カードの 📌 ボタンを押す | ★ が表示され、カードが一覧の先頭側に移動する |
| 11 | アーカイブできる | カードの 📥 ボタンを押す | 通常表示ではそのカードが消える |
| 12 | アーカイブ表示を切り替えできる | 上部の `アーカイブを表示` をチェック | アーカイブ済みカードも一覧に並ぶ / 解除すると再び消える |
| 13 | 保存できる | `ファイル > 名前を付けて保存` → 任意のフォルダに `test.ideanest` で保存 | ファイルが作成される / タイトルバーが `IdeaNest - test.ideanest` (`*` なし) になる |
| 14 | 読込できる | `ファイル > 新規作成` で空にしたあと `ファイル > 開く` から `test.ideanest` を選ぶ | カード一覧 / タグ一覧 / 検索文字列 / アーカイブ表示状態が復元される |
| 15 | 未保存変更がある状態で終了時に確認が出る | カードを追加し未保存のまま `×` で閉じる | 「未保存の変更があります。保存しますか？」の確認が出る / `キャンセル` で閉じない |
| 16 | `.bak` が作成される | シナリオ 13 で保存した状態で再度何か編集して `保存` | 同じフォルダに `test.ideanest.bak` が出来ている (中身は直前の保存内容) |

## 補助: 自動スモークテスト

UI を伴わない部分 (Models / Services / JSON ラウンドトリップ) は、
クロスプラットフォームで動く `tools/IdeaNest.Smoke` でも確認できる。

```bash
dotnet run --project tools/IdeaNest.Smoke
```

`ALL CHECKS PASSED` と表示されれば、保存形式と読み書きは健全。
