# バックログ (v0.2.0 以降の候補)

優先度はあくまで現時点のメモです。実装着手前に再判断します。

## タグ管理改善

- タグの一覧画面でのリネーム / マージ / 削除
- 未使用タグの自動クリーンアップ
- タグの色付け
- ハイフン / 半角全角の正規化

## 色フィルタ

- 左ペインに色チップを並べ、色でも絞り込み可能にする
- 色 × タグの AND 条件

## カード並べ替え

- 作成日時順 / タイトル順 への切替
- 手動並べ替え (ドラッグ)
- ピン留めの中での並べ替え

## テキストエクスポート

- 選択中フィルタの結果をプレーンテキストへ書き出し
- カードごとに区切り行 (`---`) を入れる

## Markdown 風エクスポート

- 1 カード = `## タイトル` + 本文 + タグ行 の形式
- ファイル名は更新日時 + タイトル

## NoteNest 向けエクスポート

- 選択中カードを 1 つの NoteNest ノートにまとめて出力
- タグを NoteNest のタグへマッピング

## 重複アイデア検出

- 本文の n-gram 類似度で重複候補を提示
- ピン留め扱いではなく「同一視」フラグを付ける

## ランダム表示

- 「思考の壁打ち」用に 1 枚だけランダムに表示する画面
- アーカイブ済みを含めるかは選べる

## 今日のアイデア表示

- 更新日が今日 / 直近 N 日のものだけ抽出するクイックフィルタ

## UI 改善

- ダークモード
- カードのサイズ切替 (大 / 中 / 小)
- 一覧と並んでカードの詳細プレビューを表示するスプリットビュー

## カード選択モデル

現状の実装には「選択中カード」という UI 概念が無いため、選択前提のショートカット
(`Del` で削除、`Ctrl+P` でピン留め切替) は v0.1.3 でも見送った。
将来カード選択モデルを導入する場合、以下を併せて検討する。

- カードクリックで選択状態 (薄い枠線 / 影の強調) を持つ
- キーボードフォーカスをカード一覧内で移動できる (`Tab` / 矢印キー)
- `Del`: 選択中カードを削除
- `Ctrl+P`: 選択中カードのピン留め切替
- `Enter`: 選択中カードを編集ダイアログで開く

## ショートカットキー追加

- 既に実装済み: `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` /
  `Ctrl+Shift+N` / `Ctrl+F` / 検索欄での `Esc`
- 未対応 (カード選択モデル導入後): `Del`, `Ctrl+P`, カード上での `Enter`
- `Ctrl+D` (複製) など補助系

## その他検討事項

- `.ideanest` 形式のスキーマバージョン管理
- マイグレーション戦略 (v0.1.0 → v0.2.0)
