# バックログ (v0.2.0 以降の候補)

優先度はあくまで現時点のメモです。実装着手前に再判断します。

## タグ管理改善

- タグの一覧画面でのリネーム / マージ / 削除
- 未使用タグの自動クリーンアップ
- タグの色付け
- ハイフン / 半角全角の正規化

## 色フィルタ

- 左ペインに色チップを並べ、色でも絞り込み可能にする
- 色 × タグの AND 条件

## カード並べ替え

- 作成日時順 / タイトル順 への切替
- 手動並べ替え (ドラッグ)
- ピン留めの中での並べ替え

## テキストエクスポート

- 選択中フィルタの結果をプレーンテキストへ書き出し
- カードごとに区切り行 (`---`) を入れる

## Markdown 風エクスポート

- 1 カード = `## タイトル` + 本文 + タグ行 の形式
- ファイル名は更新日時 + タイトル

## NoteNest 向けエクスポート

- 選択中カードを 1 つの NoteNest ノートにまとめて出力
- タグを NoteNest のタグへマッピング

## 重複アイデア検出

- 本文の n-gram 類似度で重複候補を提示
- ピン留め扱いではなく「同一視」フラグを付ける

## ランダム表示

- 「思考の壁打ち」用に 1 枚だけランダムに表示する画面
- アーカイブ済みを含めるかは選べる

## 今日のアイデア表示

- 更新日が今日 / 直近 N 日のものだけ抽出するクイックフィルタ

## UI 改善

- ダークモード
- カードのサイズ切替 (大 / 中 / 小)
- 一覧と並んでカードの詳細プレビューを表示するスプリットビュー
- 空状態 (`.ideanest` を開いていない / カード 0 件) のガイダンス

## ショートカットキー追加

- `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S`
- `Ctrl+F` で検索欄フォーカス
- `Enter` で簡易入力欄から追加
- `Del` / `Ctrl+D` で選択カードの削除
- `Ctrl+P` でピン留め切替

## その他検討事項

- 自動保存 (n 秒ごと / 編集後 n 秒)
- `.ideanest` 形式のスキーマバージョン管理
- マイグレーション戦略 (v0.1.0 → v0.2.0)
- 検索のあいまい一致 (かな / カナ / 全半角)
